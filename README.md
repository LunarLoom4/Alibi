# Alibi

A multiplayer murder mystery game where AI agents exclusive to each suspect answer questions from the detectives about the night of the crime.
The game logic decides the truth. The LLM only puts that truth into words.

## Run the Backend

The Backend needs Python 3.15. All commands run in PowerShell from the `backend/` folder.

1. Create the Virtual Environment and activate it:

    ```powershell
    py -3.15 -m venv .venv
    .\.venv\Scripts\Activate.ps1
    ```

2. Install the exact locked Versions, then the Project itself with its Development Tools:

    ```powershell
    python -m pip install -r requirements.lock
    python -m pip install -e ".[dev]"
    ```

3. Start the Server, then open http://127.0.0.1:8000/docs/ in a Browser:

    ```powershell
    uvicorn alibi.main:app --reload --reload-dir src
    ```

4. Run the Tests:

    ```powershell
    python -m pytest
    ```

## Dependency Overview

This project separates its dependencies across three files inside `backend/`:

* **`pyproject.toml`**: The source of truth. Defines project metadata, Python version requirements (`>=3.15`), runtime packages (`dependencies`), and testing tools (`[project.optional-dependencies]`).
* **`requirements.txt`**: Auto-generated list of **production-only** dependencies pinned to exact versions.
* **`requirements.lock`**: Auto-generated snapshot of **all runtime and development dependencies** pinned to exact versions with SHA-256 hashes.


## Setup & Running the Backend

The backend requires **Python 3.15**. Run all commands below in PowerShell from the `backend/` directory.

### 1. Local Development & Testing

Use this setup when writing code or running the test suite locally.

1. **Create and activate the virtual environment:**

   ```powershell
   py -3.15 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **Install all locked dev/test dependencies and link the `alibi` package in editable mode:**

   ```powershell
   python -m pip install -r requirements.lock
   python -m pip install -e . --no-deps
   ```

   *What gets created here:*
   * `.venv/Lib/site-packages/__editable__.alibi-0.1.0.pth` and `alibi-0.1.0.dist-info/` (points Python directly to `src/alibi/` so code edits take effect immediately without reinstalling).
   * `src/alibi.egg-info/` (build metadata generated by `setuptools`).

3. **Start the development server** and open [http://127.0.0](http://127.0.0) in your browser:

   ```powershell
   uvicorn alibi.main:app --reload --reload-dir src
   ```

4. **Run the test suite** (executes across 10 worker processes via `pytest-xdist`):

   ```powershell
   python -m pytest
   ```


### 2. Production / Deployment

Use this setup on a server or inside a container where testing tools like `pytest` are not needed.

1. **Create and activate the virtual environment:**

   ```powershell
   py -3.15 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **Install production runtime packages and install `alibi` as a standard package:**

   ```powershell
   python -m pip install -r requirements.txt
   python -m pip install . --no-deps
   ```

   *What gets created here:*
   * `.venv/Lib/site-packages/alibi/` and `alibi-0.1.0.dist-info/` (copies a frozen snapshot of `src/alibi/` into the environment instead of creating an editable `.pth` link).
   * `src/alibi.egg-info/` (build metadata generated during wheel creation).

3. **Start the production server:**

   ```powershell
   uvicorn alibi.main:app --host 0.0.0.0 --port 8000
   ```


## Updating Dependencies

Whenever you add, remove, or change a package version in `pyproject.toml`, regenerate both lock files so everything stays in sync:

1. **Install `pip-tools`** (if not already in your `.venv`):

   ```powershell
   python -m pip install pip-tools
   ```

2. **Re-compile `requirements.txt` and `requirements.lock`:**

   ```powershell
   pip-compile pyproject.toml -o requirements.txt
   pip-compile pyproject.toml --extra dev --generate-hashes -o requirements.lock
   ```

3. **Sync your local environment** and commit `pyproject.toml`, `requirements.txt`, and `requirements.lock` together:

   ```powershell
   python -m pip install -r requirements.lock
   ```
